# String Methods

Strings have built-in tricks called **methods**. Here are the most useful ones:

### Uppercase, Lowercase and Titlecase

```python
name = "SARah"
print(name.upper())  # SARAH
print(name.lower())  # sarah
print(name.title())  # Sarah
```

# Replace Text

```python
message = "I like cats"
print(message.replace("cat", "dog"))  # I like dogs
```
