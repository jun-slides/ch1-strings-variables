# The `print()` function

<v-clicks>

The `print()` function outputs text to the screen - it's how your program talks to the user.

```python
print("Hello World!")
```

</v-clicks>

# Strings: Text in Python

<v-clicks>

A **string** is a sequence of characters wrapped in quotes. 

```python
print("Hello")       # Using double quotes
print('Hello')       # Single quotes work too
```

</v-clicks>
