# Comments

<v-click>

Comments are notes for humans - Python ignores them completely.

</v-click>

<v-click>

```python
# This is a comment - Python skips this line
print("Hello")  # You can also comment at the end of a line
```

</v-click>

<v-click>

**Why use comments?**

</v-click>

<v-clicks>

- Explain confusing code
- Leave notes for yourself
- Temporarily disable code

</v-clicks>

<v-click>

**Shortcut:** `Ctrl + /` (Windows) or `Cmd + /` (Mac) to toggle comments.

</v-click>
